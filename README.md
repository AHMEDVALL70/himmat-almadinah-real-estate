# همة المدينة العقارية — دليل المشروع

موقع عقاري كامل (واجهة + قاعدة بيانات حقيقية + لوحة تحكم إدارية)، بدون أي خادم دائم — كل شي يعمل عبر ملفات ثابتة (GitHub Pages أو أي استضافة مشابهة) متصلة بـ Supabase.

## 📁 هيكل الملفات

```
himmat-almadinah/
├── index.html                          # الموقع العام (ملف واحد كامل)
├── admin.html                          # لوحة التحكم الإدارية (ملف منفصل)
├── Himmat-Almedina.png                 # الشعار
├── supabase/
│   ├── schema.sql                      # قاعدة البيانات الكاملة + RLS + بيانات تجريبية
│   └── edge-functions/
│       └── send-reminders/index.ts     # تنبيهات الدفعات/الإخلاء (اختياري)
└── README.md                           # هذا الملف
```

## 🚀 الإعداد من الصفر

### 1) قاعدة البيانات (Supabase)
1. أنشئ مشروعاً على [supabase.com](https://supabase.com) (مجاني).
2. **SQL Editor** → استعلام جديد → الصق **كامل** محتوى `supabase/schema.sql` → Run.
3. الملف **آمن يتكرر تشغيله** أي عدد مرات (كل الجداول والسياسات والبيانات التجريبية تتحقق قبل أي إضافة) — لو حدّثنا الملف لاحقاً، فقط أعد تشغيله كاملاً.
4. لإنشاء حساب المدير (لتسجيل الدخول بلوحة التحكم): **Authentication → Users → Add user** → بريد وكلمة مرور، فعّل "Auto Confirm User".

### 2) الموقع (`index.html`)
1. تأكد من وجود بيانات الاتصال الصحيحة أعلى الكود:
   ```js
   const SUPABASE_URL = "https://xxxxx.supabase.co";
   const SUPABASE_ANON_KEY = "eyJ...";   // Project Settings → API → anon public
   ```
2. ارفع `index.html`، `admin.html`، و`Himmat-Almedina.png` **بنفس المجلد** على GitHub Pages (أو أي استضافة ثابتة).
3. بدون ربط صحيح، يعمل الموقع تلقائياً بـ"بيانات توضيحية" مطابقة تماماً للبيانات الحقيقية شكلاً (نفس الصور والوصف)، مع تنبيه واضح بدل الانهيار.

### 3) لوحة التحكم (`admin.html`)
- يُفتح من رابط منفصل غير ظاهر بقائمة الموقع العامة عمداً: `yoursite.com/admin.html`
- الحماية حقيقية على مستوى قاعدة البيانات (Supabase Auth + RLS)، مو مجرد كلمة مرور بالواجهة.
- التبويبات: نظرة عامة، العقارات (اعتماد/رفض)، العروض (إضافة/تعديل عروض تسويقية كاملة بالصور والوصف)، الاستفسارات.

## ✨ الميزات الكاملة

### الصفحة الرئيسية
هيرو بثيم داكن (كحلي/ذهبي)، عدّادات إحصائية متحركة، قسم "عقارات مميزة" بصور حقيقية، حركة ظهور تدريجي عند التمرير، قائمة جوال (☰) لكل الشاشات الصغيرة.

### العروض وتفاصيل العقار
فلترة (مدينة/نوع/سعر/غرف)، كل بطاقة قابلة للنقر تفتح نافذة تفاصيل كاملة (صورة، وصف تفصيلي مقسّم لأقسام، اسم المسوّق ورقم رخصته، زر خريطة، زر واتساب مباشر).

### التقييم العقاري الاسترشادي
- **حقول ديناميكية حسب نوع العقار** (4 مجموعات: سكني / أرض-مزراعة / عمارة كاملة / تجاري) — كل نوع يعرض بس الحقول المنطقية له.
- **عمارة**: عدد الأدوار وعدد الشقق بكل دور بدل "عدد الغرف"، وعدد الوحدات الإجمالي يؤثر فعلياً على السعر (قيمة استثمارية إضافية).
- **أسعار حقيقية موثّقة** لـ39 حي (من أصل 265) — مصدرها صفقات فعلية موثّقة من وزارة العدل السعودية (عبر منصة رغدان raghdan.sa، بيانات 2026). لو الحي المختار موثّق، يظهر مؤشر أخضر "✅ سعر موثّق"، ويُستخدم مباشرة بدل التقدير اليدوي. باقي الأحياء تستخدم "متوسط المدينة × تصنيف يدوي" مع مؤشر برتقالي واضح "⚠️ تقدير".
- **تحديث لحظي**: السعر يتحدّث تلقائياً فور تغيير أي حقل أو إضافة، بدون ضغط زر.
- حاسبة تمويل عقاري منفصلة (قسط شهري تقريبي).

### إضافة عقار
نفس الحقول الديناميكية حسب النوع، وصف تفصيلي حر، رابط خريطة، رقم رخصة عقارية/إعلانية اختياريين (للمسوّقين المرخّصين).

### العقود
توليد عقد سكني/تجاري مع معاينة نصية فورية، وحفظ جدول الدفعات كاملاً بقاعدة البيانات عبر دالة آمنة (`create_contract_with_schedule`، صلاحية `SECURITY DEFINER`) — المفتاح العام (`anon key`) لا يلمس جداول العقود مباشرة أبداً.

### التحليلات
جدول ورسم بياني للعقارات المعتمدة فعلياً، مبني على بيانات حقيقية من قاعدة البيانات.

### المساعد الإرشادي
مساعد داخل الصفحة يفهم استفسارات حرة ("شقة في جدة تحت 900 ألف") ويبحث فعلياً بقاعدة البيانات — مبني على قواعد مبرمجة (كلمات مفتاحية)، **وليس نموذج ذكاء اصطناعي خارجي**، ومُسمّى بصراحة كذلك بالواجهة.

### لوحة التحكم الإدارية
اعتماد/رفض/حذف عقارات، إضافة وتعديل عروض تسويقية كاملة (صورة، وصف، مسوّق، رخصة)، إدارة استفسارات التواصل — كل هذا كان يدوياً عبر SQL Editor، صار بواجهة كاملة.

## 🔒 الأمان
- RLS مفعّل على كل الجداول؛ لا قراءة/كتابة مباشرة إلا حسب الحاجة الفعلية.
- كل عقار مُضاف من زائر يُجبر على حالة `pending` بواسطة trigger بقاعدة البيانات (ما فيه طريقة يتحايل بها الزائر ليصير `approved` مباشرة).
- كتابة العقود حصراً عبر دالة `SECURITY DEFINER`، لا وصول مباشر لجداول `contracts`/`parties`.
- لوحة التحكم محمية بـ Supabase Auth حقيقي، مو كلمة مرور بجافاسكربت (قابلة للتجاوز بسهولة عبر أدوات المطوّر).
- كل استدعاءات قاعدة البيانات محمية بمهلة قصوى (timeout) ومعالجة أخطاء، فأي انقطاع اتصال يرجع تلقائياً لبيانات توضيحية بدل تعطّل الصفحة.

## ⚠️ قيود صادقة يجب معرفتها
- **التقييم استرشادي دائماً**، حتى مع الأسعار الموثّقة — معادلة حسابية شفافة، وليس تقييماً معتمداً رسمياً ولا نموذج ذكاء اصطناعي.
- **بيانات الأسعار الحقيقية تغطي 39 حي فقط** من 265 — الباقي تقدير مبني على متوسط المدينة. لو تبي توسيع التغطية لاحقاً، بيانات إضافية موثّقة تقدر تُضاف بنفس الطريقة (`DISTRICT_PRICES` بالكود).
- **الوسطاء والمكاتب المرخّصة مسؤولة عن دقة أرقام الرخصة العقارية/الإعلانية** اللي تدخلها — الموقع بس يوفّر مكاناً لعرضها.
- إرسال تنبيهات فعلي عبر واتساب/بريد (`send-reminders`) يحتاج ربط حساب WhatsApp Business API أو مزود بريد مدفوع باسمك؛ الدالة جاهزة لكن الإرسال الفعلي غير مفعّل افتراضياً.

## 🛠️ استكشاف الأخطاء الشائعة

**"عروض توضيحية" تظهر رغم ربط قاعدة البيانات بشكل صحيح:**
هذا غالباً خطأ شبكة/DNS محلي بجهازك، مو بالكود. جرّب:
1. افتح Console (F12) وابحث عن أخطاء بلون أحمر تذكر Supabase.
2. جرّب `https://[project-ref].supabase.co/rest/v1/` مباشرة بتبويب جديد — لو ما فتح، المشكلة شبكية عندك (جرّب بيانات الجوال بدل الواي فاي، أو غيّر DNS جهازك لـ 8.8.8.8).
3. تأكد المشروع مو متوقف (Paused) بلوحة Supabase.

**نسخة قديمة من الموقع تظهر رغم رفع الملف الجديد:**
كاش المتصفح غالباً. جرّب Hard Refresh (Ctrl+Shift+R / Cmd+Shift+R) أو افتح بنافذة خاصة (Incognito). للتأكد من نسخة GitHub الفعلية، افتح الملف من صفحة المستودع نفسها (github.com، مو رابط الموقع المباشر) وتحقق من عدد الأسطر/آخر تعديل.

**خطأ SQL عند لصق `schema.sql`:**
انسخ من محرر نصوص حقيقي (VS Code موصى به) لا مباشرة من محادثة أو من TextEdit — بعض المحررات تعيد ترتيب النص العربي/الإنجليزي المختلط عند النسخ وتكسر الكود.

**التفاصيل الكاملة لعقار ما تظهر رغم وجودها بقاعدة البيانات:**
لو الاتصال بطيء لحظياً، الموقع يرجع للبيانات التوضيحية المحلية تلقائياً (مهلة قصوى 3 ثوانٍ لكل محاولة). البيانات التوضيحية مطابقة شكلاً للحقيقية بالضبط (نفس السعر والصورة) — لو الوصف ناقص تحديداً بهالحالة، جرّب تحديث الصفحة.

# همة المدينة العقارية — دليل المشروع

موقع عقاري كامل (واجهة + قاعدة بيانات حقيقية + لوحة تحكم إدارية + مساعد ذكاء اصطناعي)، بدون أي خادم دائم على GitHub Pages — كل شي يعمل عبر ملفات ثابتة متصلة بـ Supabase، مع خادم وسيط صغير على Cloudflare Workers للذكاء الاصطناعي فقط.

**للمهام المفتوحة والقرارات المعلَّقة، راجع `PENDING_TASKS.md` — هذا الملف بس للبنية والإعداد.**

## 🚀 الإعداد من الصفر

### 1) قاعدة البيانات (Supabase)
1. أنشئ مشروعاً على [supabase.com](https://supabase.com) (مجاني).
2. **SQL Editor** → استعلام جديد → الصق **كامل** محتوى `supabase/schema.sql` → Run. آمن يتكرر تشغيله أي عدد مرات.
3. حساب المدير: **Authentication → Users → Add user** → بريد وكلمة مرور، فعّل "Auto Confirm User". يقدر يضيف حسابات إضافية بنفس الطريقة (كل حساب يحصل نفس الصلاحيات الكاملة تلقائياً).
4. فعّل إضافتي **pg_cron** و**pg_net** من **Database → Extensions** (مطلوبتين للتحديث الأسبوعي التلقائي للأسعار).

### 2) الموقع
1. ارفع كل الملفات (بما فيها مجلدات `css/`, `js/`, `lib/`) بنفس الهيكل أعلاه على GitHub Pages.
2. تأكد `SUPABASE_URL` و`SUPABASE_ANON_KEY` صحيحين أعلى `js/site.js` و`js/admin.js`.

### 3) لوحة التحكم
- الحماية حقيقية على مستوى قاعدة البيانات (Supabase Auth + RLS)، مو مجرد كلمة مرور بالواجهة.
- تغيير كلمة المرور متاح مباشرة من داخل لوحة التحكم (زر 🔑 بالهيدر) — ما يحتاج المرور ببريد استعادة من Supabase.

### 4) المساعد الذكي (Cloudflare Worker) — اختياري، منفصل عن GitHub
كود الخادم الوسيط (`himmat-worker.js`) **غير موجود بهذا المستودع** — محفوظ مباشرة بحساب Cloudflare الخاص بالمستخدم (Workers & Pages). التفاصيل الكاملة وأي مشاكل معروفة موثَّقة بـ `PENDING_TASKS.md` تحت قسم "المساعد الذكي".

### 5) تنبيهات الدفعات والإخلاء عبر البريد (اختياري)
```
supabase functions deploy send-reminders
supabase secrets set SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... RESEND_API_KEY=re_xxxxxxxx
```
بدون مفتاح Resend، الدالة تسجّل الرسائل بالسجلات بدل الإرسال الفعلي.

### 6) تحديث أسعار الأحياء أسبوعياً (جاهز وشغّال)
```
supabase functions deploy update-district-prices
```
جدولة أسبوعية مفعّلة (كل أحد 3 فجراً) عبر `pg_cron`. معدّل النجاح الحالي ~72%.

## ✨ الميزات الرئيسية

### الصفحة الرئيسية
هيرو ديناميكي (يعرض أحدث العروض الحقيقية)، بحث ذكي بفلترة فورية، مساعد ذكاء اصطناعي حقيقي (Gemini)، دعم كامل عربي/إنجليزي مع تبديل فوري، وضع ليلي/نهاري.

### العروض
فلترة وترتيب فوري، مفضلة محلية بدون تسجيل دخول، تفاصيل كاملة لكل عرض، شارة "تم البيع" عند البيع.

### المؤشر الاسترشادي (كان اسمه "التقييم" — غُيِّر لأسباب نظامية، راجع `PENDING_TASKS.md`)
أسعار حقيقية موثّقة تُحدَّث أسبوعياً، حاسبة تمويل عقاري. **مصطلح "تقييم عقاري" محمي نظامياً بالسعودية (يتطلب ترخيص من الهيئة السعودية للمقيّمين المعتمدين) — لا تستخدمه بأي نص جديد بالموقع.**

### العقود
توليد عقد كامل مع جدول دفعات تلقائي، تحقق شامل قبل الإرسال، **طباعة/حفظ PDF مباشر من المتصفح** (زر منفصل بعد التوليد)، تحضير كامل لربط إيجار (رقم الصك وتاريخه **إجباريان الآن**).

### لوحة التحكم
إدارة كاملة للعقارات/العروض/الاستفسارات/العقود، تعليم دفعات كمدفوعة، تحويل عقار معتمد لعرض تلقائياً، تغيير كلمة المرور المباشر.

### الأداء
ملفات منفصلة بالكامل (CSS/JS/مكتبات)، تحميل كسول للتحليلات، ضغط صور تلقائي عند الرفع.

# همة المدينة العقارية — دليل المشروع

موقع عقاري كامل (واجهة + قاعدة بيانات حقيقية + لوحة تحكم إدارية بنظام صلاحيات + مساعد ذكاء اصطناعي محمي)، بدون أي خادم دائم على GitHub Pages — كل شي يعمل عبر ملفات ثابتة متصلة بـ Supabase، مع خادم وسيط صغير على Cloudflare Workers للذكاء الاصطناعي فقط.

**للمهام المفتوحة والقرارات المعلَّقة، راجع `PENDING_TASKS.md` — هذا الملف بس للبنية والإعداد.**

## 🚀 الإعداد من الصفر

### 1) قاعدة البيانات (Supabase)
1. أنشئ مشروعاً على [supabase.com](https://supabase.com) (مجاني).
2. **SQL Editor** → استعلام جديد → الصق **كامل** محتوى `supabase/schema.sql` → Run. آمن يتكرر تشغيله أي عدد مرات.
3. حساب المدير الأول: **Authentication → Users → Add user** → بريد وكلمة مرور، فعّل "Auto Confirm User".
4. **رقّي هذا الحساب لـ`owner`** (خطوة إضافية ضرورية، وإلا ما يقدر يكتب أي شي):
   ```sql
   update auth.users set raw_app_meta_data = raw_app_meta_data || '{"role":"owner"}'::jsonb
   where email = 'بريدك-هنا';
   ```
   سجّل خروج/دخول من `admin.html` بعدها عشان الجلسة تحمل الدور الجديد.
5. عطّل **Authentication → Sign In / Providers → Allow new users to sign up** (مهم أمنياً — بدونه أي زائر يقدر يسجّل حساب لنفسه بصلاحيات كاملة).
6. فعّل إضافتي **pg_cron** و**pg_net** من **Database → Extensions** (مطلوبتين للتحديث الأسبوعي التلقائي للأسعار).

### 2) الموقع
1. ارفع كل الملفات (بما فيها `css/`, `js/`, `lib/`, `icons/`, `robots.txt`, `site.webmanifest`) بنفس الهيكل أعلاه على GitHub Pages.
2. تأكد `SUPABASE_URL` و`SUPABASE_ANON_KEY` صحيحين أعلى `js/site.js` و`js/admin.js`.

### 3) لوحة التحكم ونظام الصلاحيات
- الحماية حقيقية على مستوى قاعدة البيانات (Supabase Auth + RLS)، مو مجرد كلمة مرور بالواجهة.
- **3 أدوار:** `owner` (كل شي، بما فيها إضافة مدن/أحياء وإدارة الفريق) — `editor` (كل العمليات اليومية إلا هذي) — `viewer` (مشاهدة بس).
- إضافة عضو فريق جديد تصير من داخل لوحة التحكم نفسها (تبويب "فريق العمل") — يدعم بريد إلكتروني، اسم دخول بدون بريد، أو رقم جوال (يحتاج مزوّد SMS مفعَّل من Supabase).
- تغيير كلمة المرور متاح مباشرة من داخل لوحة التحكم (زر 🔑 بالهيدر) — يتطلب كلمة المرور الحالية (إعداد أمني من Supabase نفسه).

### 4) المساعد الذكي (Cloudflare Worker) — اختياري، منفصل عن GitHub
كود الخادم الوسيط (`himmat-worker.js`) **غير موجود بهذا المستودع** — محفوظ مباشرة بحساب Cloudflare الخاص بالمستخدم (Workers & Pages)، محمي بـ**Cloudflare Turnstile** (كابتشا خفية تمنع أي سكربت/بوت من استدعاء الرابط مباشرة واستنزاف حصة/فوترة Gemini). التفاصيل الكاملة وأي مشاكل معروفة موثَّقة بـ `PENDING_TASKS.md` تحت قسم "المساعد الذكي" و"حماية المساعد الذكي".

### 5) تنبيهات الدفعات والإخلاء عبر البريد (اختياري)
```
supabase functions deploy send-reminders
supabase secrets set SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... RESEND_API_KEY=re_xxxxxxxx
```
بدون مفتاح Resend، الدالة تسجّل الرسائل بالسجلات بدل الإرسال الفعلي.

### 6) تحديث أسعار الأحياء أسبوعياً (جاهز وشغّال)
```
supabase functions deploy update-district-prices
```
جدولة أسبوعية مفعّلة (كل أحد 3 فجراً) عبر `pg_cron`. معدّل النجاح الحالي ~72%. لأي حي فشل تلقائياً، الإدارة تقدر تُدخل سعره يدوياً من نطاق مصدر رسمي عبر لوحة التحكم (تبويب "المدن والأحياء") — يبقى ثابتاً ولا يُمحى بالتحديث الأسبوعي إلا لو الإدارة رجّعته يدوياً للتلقائي.

### 7) Google Analytics
كود التتبع (GA4) مضمَّن أصلاً بـ`index.html` (Measurement ID خاص بالمشروع الحالي). لو نسخت المشروع لموقع جديد، أنشئ خاصية GA4 خاصة فيك وحدّث المعرّف بالكود.

## ✨ الميزات الرئيسية

### الصفحة الرئيسية
هيرو ديناميكي (يعرض أحدث العروض الحقيقية)، بحث ذكي بفلترة فورية، مساعد ذكاء اصطناعي حقيقي (Gemini) محمي بـTurnstile ومصنَّف السياق (لا يختلق إجراءات الموقع)، دعم كامل عربي/إنجليزي مع تبديل فوري، وضع ليلي/نهاري.

### العروض
فلترة وترتيب فوري، مفضلة محلية بدون تسجيل دخول، **معرض صور متعددة** لكل عرض (أسهم وعداد بنافذة التفاصيل)، معاينة الوصف الكامل بتمرير الماوس على زر "التفاصيل"، شارة "تم البيع" عند البيع.

### المؤشر الاسترشادي (كان اسمه "التقييم"/"تقدير" — غُيِّرا لأسباب نظامية، راجع `PENDING_TASKS.md`)
أسعار حقيقية موثّقة تُحدَّث أسبوعياً (أو يدوياً من مصدر رسمي)، حاسبة تمويل عقاري. **مصطلحا "تقييم عقاري" و"تقدير سعري" محميان نظامياً بالسعودية (يتطلبان ترخيص من الهيئة السعودية للمقيّمين المعتمدين) — لا تُستخدمان بأي نص جديد بالموقع، استخدم "مؤشر" دائماً.**

### العقود
توليد عقد كامل (سكني/تجاري) مع جدول دفعات تلقائي، تحقق شامل قبل الإرسال (يشمل نوع/جنسية المؤجر والمستأجر وعدد الدفعات كحقول إجبارية)، **طباعة/حفظ PDF مباشر من المتصفح**، تحضير كامل لربط إيجار (رقم الصك وتاريخه إجباريان).

### لوحة التحكم
إدارة كاملة للعقارات/العروض/الاستفسارات/العقود، **نظام صلاحيات 3 مستويات (owner/editor/viewer)**، **إدارة فريق العمل** (إضافة/حذف/تعطيل عضو، تغيير كلمة مروره)، **إدارة المدن والأحياء** (إضافة مدينة/حي جديد يظهر تلقائياً بالموقع العام)، **إدخال سعر حي يدوياً** من مصدر رسمي، **توليد وصف تسويقي بالذكاء الاصطناعي** لأي عرض، تحويل عقار معتمد لعرض تلقائياً، تجاوب كامل مع الجوال.

### الأداء
ملفات منفصلة بالكامل (CSS/JS/مكتبات)، شعار WebP (87% أصغر)، إنفوجرافيك تحليلات مبني بـHTML/CSS خالص (بدون أي مكتبة رسم بياني خارجية)، ضغط صور تلقائي عند الرفع.

### السيو والتحليلات
`robots.txt`، Favicon كامل + دعم شاشة الجوال الرئيسية، Google Analytics (GA4) مربوط.

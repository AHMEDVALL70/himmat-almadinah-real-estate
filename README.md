# همة المدينة العقارية — دليل المشروع

موقع عقاري كامل (واجهة + قاعدة بيانات حقيقية + لوحة تحكم إدارية)، بدون أي خادم دائم — كل شي يعمل عبر ملفات ثابتة (GitHub Pages أو أي استضافة مشابهة) متصلة بـ Supabase.

## 📁 هيكل الملفات

```
himmat-almadinah/
├── index.html                                    # الموقع العام (ملف واحد كامل)
├── admin.html                                    # لوحة التحكم الإدارية (ملف منفصل)
├── Himmat-Almedina.png                           # الشعار
├── .nojekyll                                     # يمنع GitHub Pages من معالجة الملفات عبر Jekyll (كان يسبب فشل نشر متقطع)
├── supabase/
│   ├── schema.sql                                # قاعدة البيانات الكاملة + RLS + بيانات تجريبية
│   └── functions/
│       ├── send-reminders/index.ts               # تنبيهات الدفعات/الإخلاء عبر البريد
│       └── update-district-prices/index.ts       # تحديث أسبوعي تلقائي لأسعار الأحياء من رغدان
└── README.md                                     # هذا الملف
```

## 🚀 الإعداد من الصفر

### 1) قاعدة البيانات (Supabase)
1. أنشئ مشروعاً على [supabase.com](https://supabase.com) (مجاني).
2. **SQL Editor** → استعلام جديد → الصق **كامل** محتوى `supabase/schema.sql` → Run.
3. الملف **آمن يتكرر تشغيله** أي عدد مرات (كل الجداول والسياسات والبيانات التجريبية تتحقق قبل أي إضافة) — لو حدّثنا الملف لاحقاً، فقط أعد تشغيله كاملاً.
4. لإنشاء حساب المدير (لتسجيل الدخول بلوحة التحكم): **Authentication → Users → Add user** → بريد وكلمة مرور، فعّل "Auto Confirm User".
5. فعّل إضافتي **pg_cron** و**pg_net** من **Database → Extensions** (مطلوبتين للتحديث الأسبوعي التلقائي للأسعار).

### 2) الموقع (`index.html`)
1. تأكد من وجود بيانات الاتصال الصحيحة أعلى الكود (`SUPABASE_URL` و`SUPABASE_ANON_KEY`).
2. ارفع `index.html`، `admin.html`، `Himmat-Almedina.png`، و`.nojekyll` **بنفس المجلد الجذر** على GitHub Pages.
3. بدون ربط صحيح، يعمل الموقع تلقائياً بـ"بيانات توضيحية" مطابقة تماماً للبيانات الحقيقية شكلاً، مع تنبيه واضح بدل الانهيار.

### 3) لوحة التحكم (`admin.html`)
- يُفتح من رابط منفصل غير ظاهر بقائمة الموقع العامة (بس متاح عبر أيقونة 🔐 بشريط التنقل، وقائمة "المزيد").
- الحماية حقيقية على مستوى قاعدة البيانات (Supabase Auth + RLS)، مو مجرد كلمة مرور بالواجهة.
- التبويبات: **نظرة عامة**، **العقارات** (اعتماد/رفض)، **العروض** (إضافة/تعديل عروض تسويقية كاملة بالصور والوصف)، **الاستفسارات**، **العقود** (عرض كل العقود المُوثَّقة مع تفاصيل الأطراف وجدول الدفعات).

### 4) تنبيهات الدفعات والإخلاء عبر البريد (اختياري، لكن جاهز فعلياً)
تُرسل تلقائياً قبل 15 يوماً وقبل 3 أيام من موعد أي دفعة، وقبل 60 يوماً من نهاية أي عقد.
1. ثبّت [Supabase CLI](https://supabase.com/docs/guides/cli) على جهازك.
2. `supabase login` ثم `supabase link --project-ref <رمز-مشروعك>`.
3. انشر الدالة: `supabase functions deploy send-reminders`
4. اربطها بمشروعك: `supabase secrets set SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=...`
5. لتفعيل الإرسال الفعلي: أنشئ حساباً مجانياً على [resend.com](https://resend.com)، ثم:
   `supabase secrets set RESEND_API_KEY=re_xxxxxxxx`
6. لجدولتها يومياً، فعّل سطر `cron.schedule('daily-payment-reminders', ...)` بآخر `schema.sql`.

بدون مفتاح Resend، الدالة تعمل بأمان وتسجّل الرسائل بالسجلات (Logs) بدل الإرسال الفعلي — ما فيها أي تعطّل.

### 5) تحديث أسعار الأحياء أسبوعياً (جاهز وشغّال فعلياً)
تسحب الدالة سعر المتر لكل حي عندنا من صفحته المخصصة على منصة [رغدان](https://raghdan.sa)، وتحدّث جدول `district_prices` — الذي يقرأ منه الموقع تلقائياً بدل الأرقام الثابتة القديمة.

1. انشر الدالة (عبر CLI أو مباشرة من محرر لوحة Supabase): `supabase functions deploy update-district-prices`
2. اختبرها يدوياً من **Edge Functions → update-district-prices → Test**.
3. الجدولة الأسبوعية مفعّلة فعلياً (كل أحد 3 فجراً) عبر:
   ```sql
   select cron.schedule(
       'weekly-district-prices-update',
       '0 3 * * 0',
       $$
       select net.http_post(
           url := 'https://<project-ref>.supabase.co/functions/v1/update-district-prices',
           headers := jsonb_build_object('Authorization', 'Bearer <service_role_key>')
       );
       $$
   );
   ```
4. **معدّل النجاح الحالي: ~72%** (191 من 265 حي) — الباقي إما أحياء صغيرة عندها "بيانات غير كافية" أصلاً على رغدان نفسها، أو أخطاء اتصال شبكة مؤقتة تختفي تلقائياً بالتشغيلة التالية.
5. لمتابعة سجل التشغيل: `select * from cron.job_run_details order by start_time desc limit 5;`

## ✨ الميزات الكاملة

### الصفحة الرئيسية
- **هيرو ديناميكي حقيقي**: الخلفية تعرض أحدث 6 عروض منشورة فعلياً (صورها الحقيقية + تسمية توضيحية)، تتحرك تلقائياً، وتتحدّث فوراً كل ما تضيف عرض جديد — بدل صور ثابتة عامة.
- **بحث ذكي بفلترة فورية** فوق صورة الهيرو (مدينة/نوع/ميزانية) مع عداد نتائج حي، يطبّق نفس الفلترة على قسم العروض عند الضغط.
- **تأثير آلة كاتبة** لجملة الوصف الرئيسية (تُكتب حرف حرف عند فتح الصفحة)، وحركة طفو خفيفة مستمرة لعمود النص كامل.
- خلفية هيرو منفصلة للوضع الفاتح (أبيض دافئ فخم) عن الداكن.
- عدّادات إحصائية متحركة (تظهر فقط بعد اكتمال البيانات الحقيقية، بدون ومضة أصفار).
- قائمة جوال (☰) لكل الشاشات الصغيرة، وأيقونة دخول سريعة للوحة التحكم (🔐 تسجيل الدخول) بجانب مبدّل اللغة.

### العروض وتفاصيل العقار
- فلترة (مدينة/نوع/سعر/غرف)، ونظام تسجيل نقاط مطابقة (Match Score) يرتب النتائج حسب تفضيلات الزائر.
- **تبويبات ترتيب فورية**: الأحدث / الأعلى خصماً / الأعلى سعراً / الأقل سعراً — تبديل لحظي بدون استعلام جديد.
- **زر مفضلة (❤️)** على كل بطاقة — يُحفظ محلياً بمتصفح الزائر (localStorage) بدون تسجيل دخول.
- كل بطاقة قابلة للنقر تفتح نافذة تفاصيل كاملة (صورة، وصف تفصيلي، اسم المسوّق ورقم رخصته، زر خريطة، زر واتساب مباشر).
- شارة الخصم تظهر فقط لو فيه خصم حقيقي (> 0%).

### التقييم العقاري
- أسعار حقيقية موثّقة لأحياء رئيسية (تُحدَّث أسبوعياً تلقائياً من رغدان)، مع وصف دقيق لطبيعة البيانات (تراكمية/وسيط آخر 12 شهر، مو سنة واحدة بالضبط) بدل ادّعاءات مضلِّلة.
- تقدير استرشادي (متوسط المدينة × تصنيف الحي) للأحياء اللي ما عندها بعد سعر حقيقي.
- حاسبة تمويل عقاري.

### العقود
- توليد عقد إيجار/تجاري كامل مع جدول دفعات تلقائي (سنوي/نصف سنوي/ربع سنوي/شهري).
- حقول: تاريخ ميلاد كل طرف، نوع الهوية (وطنية/إقامة)، الجنسية، رقم الصك، رقم الدور — **تحضير جاهز لربط شبكة إيجار الحكومية مستقبلاً** (الحقول موجودة، الربط الفعلي بانتظار إتمام التسجيل الرسمي كمنصة تسويق عقاري لدى إيجار).
- **تحقق شامل قبل الإرسال**: يرفض العقد الناقص أو غير المنطقي (حقول فاضية، تواريخ غير صحيحة، مساحة/إيجار صفر أو سالب) ويعلّم الحقول الناقصة بالأحمر، بدل إرسال عقد ناقص للوسيط.
- **زر واحد "إرسال العقد للتوثيق"**: يولّد + يحفظ بقاعدة البيانات + يفتح واتساب همة المدينة (966530500906+) بنص العقد كامل جاهز، بنفس اللحظة.

### لوحة التحكم — تبويب العقود
- قائمة بكل العقود (رقم، أطراف، عقار، إيجار، عدد دفعات، حالة، تاريخ).
- بحث فوري برقم العقد أو اسم أي طرف.
- زر "عرض التفاصيل" لكل عقد: يعرض بيانات الطرفين الكاملة (هوية، نوعها، جنسية، تاريخ ميلاد، جوال) ورقم الصك، وجدول الدفعات كامل (تاريخ الاستحقاق، المبلغ، حالة السداد).

### الأداء
- حذف مكتبة xlsx غير المستخدمة (كانت 624 كيلوبايت من أصل ~1.5 ميجابايت للملف كامل).
- تحميل كسول لقسم "التحليلات" (يشتغل فقط لمن يدخله فعلياً، مو بكل تحميل صفحة).
- وسوم Open Graph وTwitter Card لمشاركة أفضل على واتساب ووسائل التواصل.
